# 강의 실습을 내 PC에서 다시 해 보려면 — 필요한 도구·자료·출처

2026년 11월 공주여성새로일하기센터 「AI 에이전트 활용」 강의(11.10. A반, 11.17. B반)에서 함께 해 본 실습을 집이나 사무실 PC에서 다시 해 볼 때 필요한 것을 모았습니다. 실습마다 **무엇을 설치하고, 어떤 계정·키가 필요하고, 어디서 자료를 가져왔는지** 적었습니다.

> - 이 문서는 강의 때 실제로 쓴 도구 코드와 준비자료를 보고 적었습니다(2026-11-10 기준). 코드에서 확인하지 못한 내용은 **"확인 필요"** 로 표시했습니다.
> - 버전은 강의 PC에 설치되어 있던 판입니다. 더 새 판이어도 대부분 그대로 동작합니다.
> - 명령은 **Windows PowerShell** 기준입니다. macOS 대안이 있으면 한 줄로 덧붙였습니다.
> - API 키 받는 법은 [api-keys.md](api-keys.md)에 따로 정리되어 있어 여기서는 링크만 겁니다.

## 먼저 알아 둘 것 — 강의실 장치와 내 PC의 차이

강의 때는 강사 PC에 미리 만들어 둔 **준비 도구(파이썬 스크립트)** 와 **강의실 사이트(채팅·투표·설문)** 가 있었습니다. 내 PC에는 이 둘이 없으므로 아래처럼 바꿔 생각하시면 됩니다.

| 강의 때 | 내 PC에서 다시 할 때 |
|---|---|
| 수강생이 강의실 채팅에 적은 주제·키워드를 AI가 가져옴 | 원하는 주제·키워드를 **Claude에게 직접 말합니다**("키워드는 육아, 물가, AI 배움으로 해 줘"). |
| 강의실 투표로 주제·꾸밈을 고름 | Claude가 후보를 보여 주면 내가 고릅니다. |
| 강의실 설문으로 휴대폰 응답을 받음 | Google 설문지 같은 무료 설문 도구로 응답을 받아 CSV로 내려받은 뒤 Claude에게 분석을 맡깁니다. |
| 준비 도구가 HTML 틀·숫자 검사를 맡음 | Claude에게 "한 장짜리 HTML로 만들어 줘, 숫자는 원자료와 대조해 줘"라고 요청합니다. 도구가 없어도 같은 결과물을 만들 수 있지만, 시간이 조금 더 걸립니다. |
| 결과 공개(강사 PC가 한/글로 PDF 변환 후 GitHub Pages에 올림) | 내 PC에서 PDF로 저장하거나, 원하면 GitHub Pages로 공개합니다([7절](#7-공개공유--github-pages)). |

> 강의용 준비 도구 자체는 이 레포에 들어 있지 않습니다. 공개 여부는 **확인 필요**. 아래 표의 도구·출처만 갖추면 Claude Code가 같은 일을 처음부터 해 낼 수 있습니다.

## 1. 기본 도구

### 1-1. Claude Code

- **어디에**: 모든 실습. 강의 때 화면에 보인 "팀장 AI가 팀원(서브에이전트)에게 나눠 맡기는" 동작이 Claude Code 기능입니다.
- **설치**: [README 빠른 시작](../README.md#1-claude-code-설치)을 따릅니다.
  - Windows PowerShell: `irm https://claude.ai/install.ps1 | iex`
  - macOS: `curl -fsSL https://claude.ai/install.sh | bash`
- **확인**: 새 터미널에서 `claude --version` (강의 PC: 2.1.321).
- **계정**: Claude 유료 구독(Pro 이상) 또는 Anthropic Console 계정.
- **웹 검색·웹 읽기**: Claude Code에 들어 있는 `WebSearch`·`WebFetch` 기능을 씁니다. 따로 키가 필요 없습니다. 처음 쓸 때 허용 여부를 묻는 창이 뜨면 허용합니다.
- **흔한 막힘**
  - `claude` 명령을 못 찾음 → 설치 뒤 **터미널을 새로 열어야** 합니다.
  - 일부 사이트(예: 네이버 검색 결과 페이지)는 웹 읽기가 막힙니다. 강의 준비 때도 막혀서 Google 뉴스 RSS·기관 원문으로 돌렸습니다.

### 1-2. Git

- **어디에**: 이 레포·Agent4D 내려받기, 결과물 공개(⑨·[7절](#7-공개공유--github-pages)). Windows에서는 Claude Code가 Git Bash를 쓰므로 **설치를 권장**합니다.
- **설치**: Windows — [Git for Windows](https://git-scm.com/downloads/win) 내려받아 설치(기본값으로 다음만 눌러도 됩니다) 또는 `winget install --id Git.Git -e`. macOS — `xcode-select --install`.
- **확인**: `git --version` (강의 PC: 2.42).
- **계정**: 내려받기만 하면 필요 없습니다. 공개하려면 GitHub 계정(무료).

### 1-3. Node.js

- **어디에**: ①② 한글 문서 도구 kordoc(`npx`로 실행), Agent4D.
- **설치**: Windows — [nodejs.org](https://nodejs.org/ko)에서 **LTS** 판 설치 또는 `winget install OpenJS.NodeJS.LTS`. macOS — 같은 사이트 설치 파일 또는 `brew install node`.
- **버전**: kordoc이 **Node 20 이상**을 요구합니다(kordoc `package.json`의 `engines`). 강의 PC는 24.13.
- **확인**: `node --version`, `npx --version`.
- **흔한 막힘**: 처음 `npx kordoc ...`을 실행하면 내려받기 확인을 묻습니다. 명령에 `-y`를 붙이면(`npx -y kordoc@4.24.25 ...`) 묻지 않고 진행합니다. 회사망에서 npm 내려받기가 막혀 있으면 집이나 다른 망에서 한 번 받아 두면 다음부터는 캐시로 동작합니다.

### 1-4. Python과 패키지

- **어디에**: ③ 설문 차트, ④ 모션그래픽 렌더, ⑥⑦ 지도 자료 처리, ① 결과를 PDF로 바꿀 때(한/글 자동화).

- **확인**: `python --version` (macOS는 `python3 --version`).
- **실습별 패키지**(강의 PC 판)

  | 패키지 | 판 | 어느 실습 | 설치 |
  |---|---|---|---|
  | `matplotlib` | 3.10.6 | ③ 설문 결과 차트 그림 | `python -m pip install matplotlib` |
  | `playwright` | 1.58.0 | ④ 화면을 한 장씩 찍어 영상으로 | `python -m pip install playwright` 후 `python -m playwright install chromium` |
  | `imageio-ffmpeg` | 0.6.0 | ④ mp4 인코딩(ffmpeg 실행 파일이 함께 들어 있음) | `python -m pip install imageio-ffmpeg` |

- **나머지 도구는 표준 라이브러리만** 씁니다(설문 문항 만들기, 지도 자료 정리, 결과 화면 만들기 등).
- **흔한 막힘**
  - 한글이 깨지거나 `UnicodeEncodeError` → Windows에서는 `python -X utf8 스크립트.py` 처럼 `-X utf8`을 붙여 실행합니다. 강의 도구도 모두 이렇게 실행했습니다.
  - `pip` 명령을 못 찾음 → `python -m pip ...` 꼴로 씁니다.
  - Python을 여러 개 설치했다면 Claude에게 "이 PC의 파이썬 경로를 확인하고 그걸로 실행해 줘"라고 말해 두면 헷갈리지 않습니다.

## 2. 한글 문서

### 2-1. HWPX 만들기·읽기 — kordoc

- **어디에**: ① 마크다운 초안 → 한글 보고서(HWPX), 첫 쪽 미리보기 그림. ② 한글 보고서를 쪽 번호 붙여 읽기.
- **도구**: [chrisryugj/kordoc](https://github.com/chrisryugj/kordoc)(npm `kordoc`, MIT). 강의 때 고정한 판 **4.24.25**.
- **설치**: Node.js만 있으면 따로 설치하지 않고 `npx`로 바로 씁니다.
- **강의 때 쓴 명령**(그대로 따라 해 볼 수 있습니다)
  ```powershell
  npx -y kordoc@4.24.25 generate out/보고서.md -o "out/보고서.hwpx" --preset 개조식 --no-toc --org "기관 이름" --date "2026-11-10" --silent
  npx -y kordoc@4.24.25 validate "out/보고서.hwpx"
  npx -y kordoc@4.24.25 render "out/보고서.hwpx" --format png -d out/pages --silent
  ```
  - `generate` 마크다운 → HWPX, `validate` 파일 구조 검사, `render` 쪽마다 그림(PNG)으로.
  - 보고서 읽기(②)는 kordoc으로 마크다운 원문과 쪽별 그림(SVG)을 만든 뒤, 쪽마다 글자를 맞춰 "[3쪽]" 같은 표시를 붙였습니다.
- **한/글 설치 필요?** 만들기·읽기·그림 미리보기에는 **필요 없습니다**.
- **키**: 필요 없습니다([api-keys.md 1절](api-keys.md#1-kordoc--한글-문서-도구-키-불필요)).
- **흔한 막힘**: 판을 고정하지 않으면(`npx kordoc`) 그날 최신판을 받아 옵니다. 결과 모양이 달라지면 `kordoc@4.24.25`처럼 판을 적어 주세요.

### 2-2. HWPX → PDF 변환

- **어디에**: ① 보고서를 웹에 올리거나 휴대폰으로 보낼 때. 강의 때는 [⬆ 결과 공개] 단추를 누르면 **강사 PC의 한/글**이 PDF로 바꿨습니다(수강생 PC에서는 하지 않음).
- **강의 때 방법**: 한/글(한컴오피스) + Python `pyhwpx`로 파일을 열어 PDF로 저장만 하고, `PyMuPDF`로 PDF 속 전화번호·이메일을 가리고 문서 정보(작성자 등)를 비웠습니다. 변환은 한/글 창 하나씩 순서대로 했습니다.
- **한/글이 꼭 있어야 하나?** 이 방법은 **Windows + 한/글 설치**가 필요합니다. 한/글이 없으면:
  1. **kordoc 렌더** — kordoc README에 PDF 렌더 기능이 안내되어 있습니다. 명령 형식(`render --format pdf` 여부)과 한/글과 같은 모양이 나오는지는 **확인 필요**.
  2. **한컴오피스 뷰어**(무료)로 HWPX를 열고 인쇄 → "Microsoft Print to PDF"로 저장. 뷰어 지원 범위는 **확인 필요**.
  3. PDF가 꼭 필요 없으면 kordoc `render`로 만든 쪽별 PNG나 `out/보고서.md`를 그대로 공유합니다.
- **흔한 막힘**
  - 한/글 자동화 때 "보안 승인" 창이 뜨며 멈춤 → 한/글 보안 모듈 등록이 필요합니다. 처음 한 번은 사람이 창을 확인하고, 자동화를 계속 쓸 거면 Claude에게 "pyhwpx 보안 모듈 설정 방법을 찾아 줘"라고 요청하세요.
  - 변환이 끝나지 않고 한/글이 남아 있음 → 작업 관리자에서 **그 한/글 창만** 끕니다(다른 한/글 문서까지 같이 꺼지지 않게).

### 2-4. pdf.js — 웹에서 PDF 보기

- **어디에**: ① 결과 공개 페이지에서 PDF를 휴대폰에서도 바로 보이게 했습니다.
- **판**: pdf.js **3.11.174**(UMD 판). 스크립트는 cdnjs, 한글 표시에 필요한 CMap·표준 글꼴은 jsDelivr의 같은 판에서 불러왔습니다(cdnjs 판에는 CMap이 없음).
  - 스크립트: `https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.min.js`, 작업자 `.../pdf.worker.min.js`
  - CMap: `https://cdn.jsdelivr.net/npm/pdfjs-dist@3.11.174/cmaps/`, 표준 글꼴 `.../standard_fonts/`
- **설치·키**: 없습니다(인터넷만 연결). 내 PC에서 보기만 할 거면 필요 없습니다 — 브라우저가 PDF를 바로 엽니다.
- **흔한 막힘**: 한글이 네모(□)로 보이면 `cMapUrl`·`cMapPacked: true` 설정이 빠진 경우입니다. 불러오기가 실패하면 PDF 내려받기 링크를 함께 두면 됩니다(강의 페이지도 그렇게 했습니다).

## 4. 지도

### 4-1. Leaflet — 지도 그리기

- **어디에**: ⑥⑦ 지도 화면. ⑥에는 그래프용 **Chart.js**도 함께 썼습니다.
- **판**: Leaflet **1.9.4**, Chart.js **4.4.1**.
- **설치**: 설치하지 않습니다. 강의 때는 인터넷이 끊겨도 열리도록 `leaflet.js`·`leaflet.css`·`chart.umd.min.js`를 **결과 폴더(`lib/`)에 복사**해 두고 불러왔습니다. 내 PC에서는 Claude에게 "Leaflet 1.9.4를 써서 지도 HTML을 만들어 줘"라고 하면 CDN 주소(예: unpkg·cdnjs)를 넣어 줍니다.
- **키**: 필요 없습니다(BSD-2 라이선스, Chart.js는 MIT).

### 4-2. 바탕 지도 타일 — OpenStreetMap

- **어디에**: ⑥⑦ 지도 바탕.
- **주소**: `https://tile.openstreetmap.org/{z}/{x}/{y}.png` — 화면 모서리에 `© OpenStreetMap` 저작권 표시를 꼭 넣습니다.
- **어둡게 보이게**: 타일 자체는 밝은 지도이고, CSS 필터(`invert`·`hue-rotate` 등)로 어둡게 바꿨습니다.
- **키**: 필요 없습니다. 다만 OSM 타일은 **가벼운 사용만** 허락됩니다(타일 이용 정책). 많은 사람에게 공개하는 서비스라면 다른 타일 제공자를 쓰는 편이 안전합니다(대부분 무료 키 발급 필요).
- **쓰지 않은 것**: 어두운 지도 타일(CARTO)은 강의 준비 때 키 없이 요청하자 "API KEY REQUIRED"가 돌아와 쓰지 않았습니다. 키 발급 조건은 **확인 필요**.

### 4-3. 주소 → 좌표 (Nominatim)

- **어디에**: ⑥ 채용공고 근무지, ⑦ 지역아동센터 주소를 지도 위 점으로 바꿀 때.
- **서비스**: [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/) — 키 없이 무료.
- **지킬 것**(Nominatim 이용 정책): **1초에 1건 이하**, 내 프로그램을 알 수 있는 User-Agent 이름 넣기, 같은 주소를 반복해 묻지 않도록 **결과를 캐시 파일에 저장**하기, 대량 일괄 조회 금지.
- **강의 때 방법**
  1. 캐시(`geocache.json`, 주소 338개)부터 찾고, 처음 보는 주소만 Nominatim에 물음(한 번 실행에 새 질의 최대 60건).
  2. 시도 순서: 도로명+건물번호 → 회사·매장 이름(공주시 범위 안) → 도로명(+읍면동) → **읍·면·동 중심점** → 공주시 중심.
  3. 중심점으로 대신한 공고는 "위치 근사"로 표시했습니다. 읍·면·동 중심점 하나(유구읍)는 실제 읍내 위치로 손으로 고쳤습니다.
- **흔한 막힘**: 한국 주소는 Nominatim에서 못 찾는 경우가 꽤 있습니다. 이럴 때 더 정확한 대안은 국내 지오코딩 API(예: 카카오 로컬 API, 브이월드 검색 API)이며 **무료 키 발급이 필요**합니다. 강의에서는 쓰지 않아 신청 절차·한도는 **확인 필요**.

## 5. 렌더링 — 모션그래픽

강의 때 모션그래픽은 이렇게 만들었습니다: AI 팀원들이 장면 글을 쓰면 → 프로그램이 HTML 애니메이션(1920×1080)을 만들고 → **헤드리스 브라우저**가 1280×720·30fps로 한 장씩 찍어 → **ffmpeg**가 H.264 mp4로 묶었습니다. 30초 안팎 영상 렌더에 약 40초 걸렸습니다(강의 PC 기준). 배경음은 외부 음원 없이 코드(numpy)로 합성했습니다.

### 5-1. 헤드리스 브라우저 — Playwright Chromium

- **설치**: `python -m pip install playwright` 다음 `python -m playwright install chromium` (Chromium 내려받기 약 150MB 안팎, **확인 필요**). macOS도 같습니다.
- **판**: playwright 1.58.0.
- **흔한 막힘**
  - `Executable doesn't exist` → `python -m playwright install chromium`을 안 한 경우입니다.
  - **헤드리스 브라우저는 한 번에 하나만** 돌리세요. 여러 개를 동시에 돌리면 PC가 멈출 수 있습니다(강의 준비 때 실제로 겪었습니다). 강의 도구도 다른 헤드리스 브라우저가 돌고 있으면 기다렸다가, 계속 바쁘면 렌더를 미루고 HTML 재생본으로 마무리했습니다.
  - 렌더가 안 되면 `motion.html`을 브라우저로 열기만 해도 애니메이션이 재생됩니다(영상 파일만 없을 뿐).

### 5-2. ffmpeg — mp4 만들기

- **설치**: `python -m pip install imageio-ffmpeg` — ffmpeg 실행 파일이 패키지 안에 들어 있어 **따로 설치할 필요가 없습니다**(판 0.6.0).
- 따로 쓰고 싶으면 Windows `winget install Gyan.FFmpeg`, macOS `brew install ffmpeg`.
- **흔한 막힘**: OneDrive·네이버 MYBOX 같은 **동기화 폴더에 mp4를 바로 쓰면 파일이 손상된 적**이 있습니다. 임시 폴더에서 만든 뒤 복사하세요.

## 7. 공개·공유 — GitHub Pages

- **어디에**: 강의 때 실습 결과(보고서 PDF·슬라이드·지도·영상·정리 페이지)를 강사 GitHub 계정의 **GitHub Pages**로 공개했습니다. ⑨ 수업 정리 페이지는 그 공개 목록을 모아 링크를 걸었습니다.
- **필요한 것**: GitHub 계정(무료), Git, 공개 레포 하나.
- **방법(가장 간단)**
  1. GitHub에서 새 공개 레포를 만듭니다.
  2. 결과 HTML·PDF·그림을 레포에 올립니다(웹 화면에서 "Add file → Upload files"도 됩니다).
  3. 레포 **Settings → Pages** 에서 배포할 브랜치(`main`)와 폴더(`/ (root)`)를 고르고 저장.
  4. 1～5분 뒤 `https://<내 아이디>.github.io/<레포 이름>/` 에서 열립니다(강의 때 측정: 빠를 때 1분 안, 느릴 때 3～5분).
- **명령으로 올리기**: 레포 폴더에서 `git add .` → `git commit -m "결과 올리기"` → `git push`. Claude에게 "이 결과를 GitHub Pages로 공개해 줘"라고 맡겨도 됩니다(처음 한 번 GitHub 로그인 창이 뜹니다). [GitHub CLI](https://cli.github.com)(`gh`)를 설치하면 레포 만들기까지 Claude가 할 수 있습니다(`winget install GitHub.cli`, macOS `brew install gh`, 로그인 `gh auth login`).
- **공개 전에 꼭**
  - 결과물 속 **전화번호·이메일·주소·내 PC 폴더 경로**를 지웁니다. 강의 때도 공개 직전에 연락처를 가리고, 내 PC 경로가 남아 있으면 공개를 멈추게 했습니다(예: 영상 HTML 안의 `file:///C:/Windows/Fonts/...` 글꼴 경로).
  - PDF는 **문서 정보(작성자·만든 프로그램)** 에 이름이 남을 수 있습니다.
  - 공개 레포에 올린 것은 지워도 기록에 남습니다. API 키·비밀번호가 든 파일은 절대 올리지 마세요([api-keys.md](api-keys.md#키가-새었을-때)).
- **공개하지 않고 공유만**: 결과 파일을 메일·메신저로 보내거나, Google 드라이브에 올려 링크를 공유해도 됩니다. HTML 하나짜리 결과(지도·대시보드)는 받은 사람이 파일을 더블클릭하면 브라우저로 열립니다.

- 흐름: 주제 고르기 → 팀원 셋(통계 담당·자료 담당 **동시에** → 작성·확인 담당) → 마크다운 초안 → kordoc으로 HWPX·미리보기 그림.
- 통계 담당: KOSIS 조회([2-3절](#2-3-국가통계-kosis)). 자료 담당: 웹 검색 3～4회, 제목·기관·날짜·URL 정리. 작성·확인 담당: 초안의 숫자를 두 자료와 하나씩 대조해 맞지 않는 것은 지우거나 "확인 필요"로.
- 시켜 볼 말: "공주시 여성 일자리 현황을 A4 2쪽 보고서로. 통계는 KOSIS에서, 자료는 웹에서 찾아 팀원에게 나눠 맡기고, 숫자는 모두 출처와 대조한 뒤 kordoc으로 hwpx를 만들어 줘."

### ② 슬라이드 변환
- 흐름: kordoc으로 보고서를 쪽 번호 붙여 읽기 → 장별 내용 고르기 → 16:9 HTML 슬라이드(← → 넘기기) → 숫자를 원문 쪽별로 대조.
- 꾸밈 셋(A 어두운 남색·B 흰 종이·C 따뜻한 크림) 중 하나를 고르는 방식이었습니다. 집에서는 "첫 장만 꾸밈 세 가지로 먼저 보여 줘"라고 하면 됩니다.

### ③ 설문 자동화
- 흐름: 물어보고 싶은 주제 → 문항 5～8개(하나 고르기·여러 개 고르기·점수 1～5·자유 의견 1개) → 응답 받기 → 집계는 프로그램, 해석은 AI → 결과 한 장 화면 + 차트 그림.
- 집에서는 문항을 Google 설문지 등에 옮겨 응답을 받고, 응답 CSV를 Claude에게 주세요. 응답이 적을 때 강의 도구는 **가상 예시 응답**을 만들어 "예시"라고 표시했습니다 — 실제 보고에는 쓰지 마세요.
- 문항에 이름·연락처·주소처럼 **개인정보를 묻지 않도록** 하세요.

### ④ 모션그래픽(mp4)
- 필요한 것: [5절](#5-렌더링--모션그래픽) 전부 + 나눔스퀘어라운드 글꼴.
- 센터 소개 같은 사실은 **센터 홈페이지·시청 등 공식 출처**에서 확인한 것만 넣었습니다. 로고·인물 사진은 쓰지 않았습니다(초상권·상표).

### ⑤ CEO 대시보드
- 흐름: 관심 키워드 → 분야 3～4개로 묶기 → 조사 팀원 분야별 **동시에**(Google 뉴스 RSS + 웹 검색, 소식 3건·숫자 1개) → 확인 팀원이 출처를 열어 날짜·숫자 대조 → 편집 담당이 한 장 대시보드로.
- 맨 위에 "AI 초안 · 사실 확인 필요" 띠를 붙였습니다.

### ⑥ 공주시 여성 일자리 지도
- 흐름: 수집 팀원 셋 **동시에**(고용24 / 민간 포털 / 시청·대학·병원 게시판) → 중복 정리·분류 → 주소를 좌표로 → 지도 대시보드(Leaflet·Chart.js) → 검수 AI.
- 강의 전날 처음부터 다 하면 약 58분 걸렸고, 전날 자료(286건)와 좌표 캐시를 다시 써서 강의 때 약 6분으로 줄였습니다. 처음 해 보실 때는 **시간이 꽤 걸린다**는 점을 감안하세요.

### ⑦ 돌봄시설 지도
- 흐름: ⑥의 일자리 + 공식 돌봄시설 자료([3-3절](#3-3-돌봄시설-자료)) → 일자리마다 1km 안 어린이집·유치원·지역아동센터·초등학교 수 → 낮 근무 여부 → 지도.
- 거리·건수 계산은 프로그램이, "어느 곳을 골라 어떻게 설명할지"는 AI가 맡았습니다.

### ⑧ 수강생 요청 작업(웹 조사)
- 흐름: 요청 고르기 → 팀원 2～3명(찾기 담당·정리 담당·확인 담당) → 한 장 결과 화면.
- 필요한 것은 Claude Code의 웹 검색·웹 읽기뿐입니다. 로그인이 필요한 사이트, 개인정보, 불법·위험한 요청은 강의 때도 걸렀습니다.

### ⑨ 수업 정리 페이지
- 오늘 배운 것·집에서 해 볼 것·꼭 지킬 것을 한 장 HTML로 만들고 공개 결과 링크를 모았습니다.
- 공개하려면 [7절](#7-공개공유--github-pages). 내 PC에서만 볼 거면 따로 필요한 것이 없습니다.

| AI가 낸 숫자가 원문과 다름 | AI는 틀립니다 | 출처를 열어 직접 확인. 모르면 "확인 필요"로 두기 |
