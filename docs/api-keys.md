# 연동 도구와 API 키 받는 법

Claude Code 같은 에이전트에 공공 데이터를 직접 조회하는 도구를 붙이면, "OO시 고령인구 비율 알려 줘", "이 법 조문 찾아 줘" 같은 질문에 공식 출처와 함께 답하게 할 수 있습니다. 대부분의 도구는 기관에서 무료로 발급하는 **API 키(인증키)** 가 있어야 동작합니다.

> 이 문서는 2026년 11월 기준으로 웹에서 확인한 내용입니다. 기관 사이트 메뉴 이름·절차는 자주 바뀝니다. **"확인 필요"** 로 표시한 부분은 신청 화면에서 직접 확인해 주세요.
>
> **비용**: 이 문서에 나온 키는 모두 무료로 발급됩니다(작성자가 직접 발급받아 쓰고 있는 키 기준).

## 1. kordoc — 한글 문서 도구 (키 불필요)

- **무엇을 얻나**: HWP·HWPX·PDF·엑셀·워드·스캔 이미지를 마크다운으로 읽고, 마크다운으로 기안문·보고서 같은 HWPX 공문서를 만들고, 서식 빈칸 채우기·개인정보 가리기·공문서 표기법 점검까지 합니다.
- **레포**: https://github.com/chrisryugj/kordoc · npm 패키지 [`kordoc`](https://www.npmjs.com/package/kordoc)
- **설치**: Node.js가 있으면 따로 설치하지 않고 `npx kordoc <파일>` 로 바로 씁니다. Claude Code에 연결하는 방법은 레포 README의 `npx -y kordoc setup` 안내를 따르세요.
- **키**: 필요 없습니다.

## 2. 통계청 KOSIS — 국가통계

- **무엇을 얻나**: 인구·고령인구·출산율·고용률·지역내총생산·주택가격 등 국가통계를 시도·시군구 단위로, 통계표 ID(출처)와 함께 조회합니다.
- **신청 사이트**: KOSIS 공유서비스 https://kosis.kr/openapi/
- **절차**:
  1. 국가통계포털(KOSIS) 회원가입(이미 회원이면 그대로 사용). OpenAPI는 **개인 회원**만 신청할 수 있다고 안내되어 있습니다.
  2. 공유서비스 사이트에서 로그인 → 활용신청.
  3. 대부분 **자동 승인**되어 바로 인증키가 나옵니다(대용량 통계자료는 별도 승인). 회원당 키 1개로 모든 서비스를 씁니다.
  4. 유효기간은 승인일로부터 **2년**, 만료 한 달 전부터 마이페이지에서 연장합니다.
- **걸리는 시간**: 가입 포함 10분 안팎.
- **제한**: 분당 호출 수·1회 조회 셀 수 제한이 있습니다(공유서비스 이용안내 참고).

## 3. 국회 — 열린국회정보

- **무엇을 얻나**: 국회의원 정보, 의안(법률안) 검색과 심사 경과, 본회의 표결, 회의록, 입법예고 등.
- **신청 사이트**: https://open.assembly.go.kr
- **절차**:
  1. 회원가입(이메일 인증).
  2. 로그인 → 마이페이지 → OPEN API(인증키 발급) 메뉴에서 발급. 메뉴 이름은 화면에서 확인하세요.
  3. 발급 버튼을 누르면 키가 바로 표시됩니다.
- **걸리는 시간**: 10분 안팎.

### 3-1. 국회예산정책처(NABO) — 선택

- **무엇을 얻나**: 국회예산정책처 보고서·발간물, 재정경제통계(NABOSTATS) 관련 자료.
- **신청 사이트**: https://www.nabo.go.kr → 알림 & 소통 → Open API → 인증키 신청・관리
- **절차**: 위 메뉴에서 인증키를 신청합니다. 오류 코드 안내에 "승인 상태가 아닙니다"·사용기간 만료가 있어 **승인과 유효기간이 있는 방식**으로 보입니다. 회원가입 여부·승인 소요 시간·재정경제통계 수치를 API로 받을 수 있는 범위는 **확인 필요**.
- assembly-api-mcp는 이 키가 없으면 열린국회정보의 NABO 발간물 검색으로 대신합니다.

### 3-2. 국회입법조사처 — 별도 키 없음(공공데이터포털 경유)

- 국회입법조사처 연구보고서는 공공데이터포털(https://www.data.go.kr)에 국회사무처 제공 API로 올라와 있습니다("국회입법조사처 연구보고서"로 검색). 공공데이터포털 회원가입 → 해당 API 활용신청(개발계정은 자동 승인으로 안내) 순서입니다. assembly-api-mcp에서 이 API를 직접 쓰는지는 **확인 필요**.

### 3-3. 국민참여입법센터 — 선택

- **무엇을 얻나**: 입법예고·행정예고 목록과 의견.
- **신청 사이트**: https://opinion.lawmaking.go.kr (정보공개·Open API 안내)
- **절차**: 이용 신청 후 받은 사용자 ID를 `LAWMKING_OC` 에 넣습니다(assembly-api-mcp의 표기 그대로). 신청 화면 경로·승인 소요 시간은 **확인 필요**.

## 4. 법제처 — 국가법령정보 공동활용

- **무엇을 얻나**: 현행 법령·조문·별표, 판례, 헌재 결정, 법령해석례, 자치법규(조례), 신구조문 비교.
- **신청 사이트**: https://open.law.go.kr
- **절차**:
  1. 회원가입.
  2. OPEN API → OPEN API 신청에서 쓸 API(법령·판례 등)를 **종류별로 체크**해 신청합니다. 체크하지 않은 API는 호출이 거부됩니다.
  3. 신청할 때 API를 호출할 컴퓨터(서버)의 **공인 IP·도메인을 등록**합니다. 집·사무실 PC에서 쓰면 그 PC의 공인 IP를 넣습니다. IP가 바뀌면(와이파이 변경 등) 다시 등록해야 할 수 있습니다.
  4. 승인 뒤 **OC 값**으로 호출합니다. OC는 보통 가입한 이메일 주소의 @ 앞부분입니다(예: 이메일이 `myname@` 으로 시작하면 OC는 `myname`). 마이페이지의 API인증키관리에서 확인하세요.
- **걸리는 시간**: 승인에 1～2일이라는 안내가 있으나 공식 기준은 **확인 필요**. 문의: 법제처 국가법령정보 공동활용 사용신청 안내 전화(사이트 하단 표기).
- **자주 나는 오류**: "사용자 정보 검증 실패" → OC 오타, 아직 미승인, IP 미등록 중 하나인 경우가 많습니다.

## 5. 특허 — KIPRIS Plus

- **무엇을 얻나**: 특허·실용신안·상표·디자인의 자유 검색, 출원인·권리자 검색, 서지 상세.
- **신청 사이트**: https://plus.kipris.or.kr (공공데이터포털 data.go.kr의 KIPRIS 키도 쓸 수 있다고 안내되어 있습니다)
- **절차**: 회원가입 → 오픈API 활용신청에서 쓸 서비스를 신청 → 승인 후 마이페이지에서 키(ServiceKey) 확인.
- **비용**: 무료로 발급받아 쓸 수 있습니다(공공데이터포털 일부 목록의 유료 표시와 무관).
- **확인 필요**: 승인 소요 시간(즉시～1영업일이라는 제3자 안내가 있음).
- **팁**: 회사명은 KIPRIS 등록 표기(한글)로 검색해야 결과가 잘 나옵니다. 영문 표기로 0건이면 한글 음역으로 다시 찾으세요.

## 키는 어디에 넣나

**문서·코드·대화에 키 값을 그대로 붙여 넣지 마세요.** 환경변수나 `.env` 파일로 넣는 것이 원칙입니다.

### 방법 1. `.env` 파일 (도구가 지원하는 경우)

작업 폴더(또는 도구 폴더)에 `.env` 파일을 만들고 아래처럼 적습니다. 이 레포의 [`.env.example`](../.env.example)을 복사해 쓰세요.

```dotenv
KOSIS_API_KEY=여기에_발급받은_키
ASSEMBLY_API_KEY=여기에_발급받은_키
LAW_OC=여기에_OC값
KIPRIS_API_KEY=여기에_발급받은_키
```

`.env` 는 `.gitignore` 에 들어 있어 git에 올라가지 않습니다.

### 방법 2. 사용자 환경변수

Windows PowerShell(한 번만 실행, 새 터미널부터 적용):
```powershell
[Environment]::SetEnvironmentVariable("KOSIS_API_KEY", "여기에_발급받은_키", "User")
```

macOS·Linux(`~/.zshrc` 또는 `~/.bashrc` 에 추가):
```bash
export KOSIS_API_KEY="여기에_발급받은_키"
```

### 방법 3. MCP 서버 설정에 넣기

MCP 서버로 연결하는 도구는 Claude Code 설정의 `env` 항목에 키를 넣는 방식도 있습니다. 각 레포 README의 설정 예시를 따르되, 그 설정 파일을 공유하거나 git에 올리지 마세요.

### 키가 새었을 때

키가 들어간 파일을 실수로 공개했거나 남에게 보냈다면, 발급 사이트에서 **키를 폐기하고 재발급**하세요. 파일을 지우는 것만으로는 부족합니다(git 기록에 남습니다).
