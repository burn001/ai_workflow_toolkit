# 내 작업 폴더 (이 줄을 프로젝트 이름으로 바꾸세요)

이 파일은 Claude Code가 세션을 시작할 때마다 자동으로 읽는 "작업 규칙"입니다.
아래 내용을 내 일에 맞게 고쳐 쓰시면 됩니다. 길게 쓰기보다 꼭 지켰으면 하는 것만 적는 편이 잘 지켜집니다.

## 나와 이 폴더 소개 (예시 — 고쳐 쓰세요)
- 나는 OO 분야에서 일하는 연구자다. 보고서·자료 조사·행정 문서 작업이 많다.
- 이 폴더는 2026년 업무 전체를 모아 두는 곳이다.

## 소통 규칙
- 존댓말을 쓴다.
- 마크다운에서 범위는 전각 물결 `～`로 쓴다(반각 `~` 두 개는 취소선으로 잘못 보일 수 있다).
- **결정은 선택형 + 추천으로.** 내 결정이 필요하면 글로 "~할까요?"라고 묻지 말고, `AskUserQuestion` 선택형 질문으로 올린다.
  - 추천안을 첫 항목에 두고 라벨 끝에 "(추천)"을 붙인다.
  - 각 항목 설명에 결과·장단점을 한 줄로 적는다.
  - 질문 창만 봐도 이해되게, 무엇에 대한 결정인지 질문 안에 적는다.
- 숫자·인용·법령 조문처럼 틀리면 곤란한 내용은 출처를 함께 적고, 확인하지 못한 것은 "확인 필요"라고 표시한다.

## 기록 관리 체계

### 1. 일별 로그 (`_docs/log/`)
- 규칙은 `_docs/WORK_LOG.md`를 따른다.
- 진행중·예정 작업은 `_docs/log/ACTIVE.md` 표로 관리한다.
- **세션 시작 시** `/done` → 날짜 롤오버 확인, ACTIVE 현황 브리핑
- **세션 종료 시** `/done` → 오늘 한 일을 일별 로그에 기록, ACTIVE 갱신

### 2. 작업 폴더 이름
- 하위 작업 폴더는 `YY.MM.DD. 카테고리. 제목` 형식으로 만든다.
  - 예: `26.11.10. 리서치. 지역 돌봄 정책 사례 조사`
  - 예: `26.11.12. 행정. 연말 실적 보고서 초안`
- "새 작업 폴더 만들어 줘"라고 하면 `new-work-folder` 스킬이 이 형식으로 만든다.

### 3. 폴더별 `_STATUS.md`
- 각 작업 폴더 루트에 `_STATUS.md`를 둔다.
- **작업 시작 시**: `_STATUS.md`가 있으면 먼저 읽어 맥락을 파악한다. 없으면 작업 후 만든다.
- **작업 완료·중단 시**: 상태, 완료 항목, 남은 작업, 핵심 메모를 갱신한다.
- 모든 폴더에 만들 필요는 없다 — Claude가 작업한 폴더에만.

```markdown
# 작업 제목
> 최종 업데이트: YYYY-MM-DD

## 상태: 🔧 검토대기 / 📝 진행중 / ✅ 완료 / ⏸ 보류

## 완료
- [x] 완료 항목

## 남은 작업
- [ ] 미완료 항목

## 핵심 메모
- 다음 세션에서 알아야 할 것만 간결하게
```

## 보안
- API 키·비밀번호는 이 폴더의 문서에 적지 않는다. `.env` 파일이나 별도 비밀 폴더에 두고, 필요하면 "어디에 있다"만 적는다.
- 개인정보(주민번호·연락처 등)가 든 파일은 외부 서비스에 올리기 전에 반드시 나에게 확인받는다.
