# 작업 로그

> 날짜별 파일로 작업 이력을 관리합니다.

## 구조

```
_docs/
├── WORK_LOG.md          ← 이 파일 (인덱스 + 규칙)
└── log/
    ├── ACTIVE.md        ← 진행중·예정 작업 표
    ├── 2026-11-10.md    ← 오늘 로그
    ├── 2026-11-07.md
    ├── ...
    └── 2026-10.md       ← 10월 월간 아카이브
```

## 롤오버 규칙

1. **일별 로그** (`log/YYYY-MM-DD.md`)
   - 그날 한 작업을 기록합니다.
   - 세션 종료 때 오늘 날짜 파일이 없으면 새로 만듭니다.
   - 작업이 없었던 날은 파일을 만들지 않습니다.

2. **월간 아카이브** (`log/YYYY-MM.md`)
   - 달이 바뀌면 지난달 일별 로그를 하나의 월간 파일로 합칩니다.
   - 합친 뒤 개별 일별 파일은 지웁니다(사용자 승인 후).
   - 월간 파일은 날짜별 섹션을 유지하되 간결하게 요약합니다.

3. **진행중 작업** (`log/ACTIVE.md`)
   - 현재 진행중·예정인 작업 목록입니다.
   - 끝나면 그날 로그에 기록하고 ACTIVE에서 뺍니다.

## 일별 로그 템플릿

```markdown
# YYYY-MM-DD (요일)

## 작업 내역
- **[카테고리]** 작업 제목 — 상세 내용
- **[카테고리]** 작업 제목 — 상세 내용

## 메모
- 특이사항, 후속 작업 등
```

카테고리 예시: 리서치, 문헌조사, 데이터분석, 행정, 대외활동, 기획, 제안서, 자동화, 개발, 개인 — 자기 일에 맞게 고쳐 쓰세요.
